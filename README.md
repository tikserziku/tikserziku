## What I learned

- **Coordination beats raw power** — several focused agents beat one big prompt.
- **Verify by numbers** — an agent's "done" is not evidence; a re-run check is.
- **Memory makes agents a team** — without it they are colleagues with amnesia.
- **Rules before tools** — what may run where and when matters more than which model.
